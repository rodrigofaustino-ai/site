ASSINATURAS — ATUALIZAÇÃO ÚNICA DAS PERMISSÕES

Este pacote reúne todas as melhorias até a etapa 55. Nada foi aplicado pelo assistente.

1. Abra Firebase Console e selecione o projeto salamulti.
2. Entre em Firestore Database → Regras. NÃO use Storage ou Realtime Database.
3. Copie as regras publicadas e guarde uma cópia antes de editar.
4. Procure se já existe match /bibliotecaAssinaturas/{uid}/itens/{assinaturaId}.
   Se o bloco abaixo já estiver publicado, não precisa acrescentá-lo novamente.
5. Caso não exista, acrescente somente o bloco abaixo DENTRO de
   match /databases/{database}/documents { ... }
   e no mesmo nível de match /alunos/{alunoId}, antes dos dois fechamentos finais.
6. Preserve todos os outros blocos e publique as regras.

ATENÇÃO: o bloco abaixo NÃO é um arquivo completo de regras. Não substitua as regras existentes por ele. Ele libera apenas a biblioteca privada de assinaturas da própria conta. Não modifica os acessos dos alunos, documentos, chat, anexos ou planos de aula.

BLOCO PARA ACRESCENTAR

// Acrescentar dentro de match /databases/{database}/documents, preservando as regras existentes.
    // Biblioteca privada: cada conta gerencia somente suas imagens.
    match /bibliotecaAssinaturas/{uid}/itens/{assinaturaId} {
      function donoBiblioteca() { return request.auth != null && request.auth.uid == uid; }
      function assinaturaValida() {
        let d = request.resource.data;
        return d.keys().hasOnly(['nome','cargo','imagem','largura','altura','criadoEm'])
          && d.keys().hasAll(['nome','cargo','imagem','largura','altura','criadoEm'])
          && d.nome is string && d.nome.size() > 0 && d.nome.size() <= 120
          && d.cargo is string && d.cargo.size() > 0 && d.cargo.size() <= 100
          && d.imagem is string && d.imagem.size() <= 80000
          && d.imagem.matches('^data:image/png;base64,[A-Za-z0-9+/]+={0,2}$')
          && d.largura is int && d.largura > 0 && d.largura <= 640
          && d.altura is int && d.altura > 0 && d.altura <= 200
          && d.criadoEm is string && d.criadoEm.size() <= 30;
      }
      allow read, delete: if donoBiblioteca();
      allow create: if donoBiblioteca() && assinaturaValida();
      allow update: if false;
    }

DEPOIS DAS REGRAS

Extraia o ZIP e envie ao Netlify a pasta que contém index.html e PUBLICACAO.json. Aguarde Published e use Ctrl + Shift + R.

Confira com documento fictício: Inserir assinatura → Cadastrar assinatura → nome/cargo/imagem → Salvar na biblioteca → Usar esta assinatura → salvar o documento. Exporte DOCX/ODT e confira a posição.

A biblioteca é a mesma no PEI e nos demais formulários. Se a janela pedir acesso, use o mesmo e-mail do Diário e a senha dessa conta do Diário. A senha não é enviada ao formulário que abriu a janela. Nenhuma imagem é aplicada automaticamente.

Excluir da biblioteca preserva as cópias já inseridas. Remover imagem no documento depende do salvamento normal do documento. Os responsáveis continuam podendo assinar à mão quando nenhuma imagem é escolhida.
